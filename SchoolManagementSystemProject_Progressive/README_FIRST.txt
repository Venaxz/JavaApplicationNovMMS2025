SCHOOL MANAGEMENT SYSTEM — PROGRESSIVE EDITABLE PROJECT
======================================================

This ZIP is arranged as requested: 34 separate stage folders plus one final integrated project.

START HERE
1. Extract the ZIP using Windows File Explorer > right-click ZIP > Extract All.
2. Open STAGE_MAP_AND_HOW_TO_USE.txt.
3. Start with Stage01_Basic_Java_Programming. Each stage contains src, README.txt and run.bat.
4. Edit Java source in Notepad++; save; run run.bat to compile and execute that stage.
5. After studying the stages, open FinalIntegratedProject and run build.bat, then run.bat.

IMPORTANT
- Each stage is a separate runnable checkpoint, not one giant Java file.
- The stage examples demonstrate the named concepts and progressively build the learning path.
- FinalIntegratedProject is the multi-file connected application. Its required entry class/file name is exactly SchoolManagementSystemProject.
- Keep Java files in their existing folders, especially in FinalIntegratedProject where package names match folder names.
- JDK 17+ is recommended. Stage 30 uses the built-in jdk.httpserver module.
