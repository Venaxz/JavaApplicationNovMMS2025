HOW THE STAGES CONNECT
- Each StageXX folder is a separate, editable learning checkpoint. Its named Java class can be compiled/run independently.
- The stages are intentionally separate so a beginner can run and understand one concept at a time. They are not intended to be compiled together because many contain their own demonstration classes and entry points.
- FinalIntegratedProject is the connected multi-file application that brings together student registration, results, payments, records, reporting, a basic GUI, networking and an educational REST endpoint.
- The final entry point is exactly SchoolManagementSystemProject.java / class SchoolManagementSystemProject. Supporting classes remain in named files and package folders; no generic Main class is used.
- Some advanced items require environment setup: JDBC needs a database and driver; REST uses JDK's jdk.httpserver module; the test stage is a no-dependency executable check rather than JUnit proper. See each stage README and the final project README.
