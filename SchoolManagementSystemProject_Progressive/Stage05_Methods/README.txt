STAGE 05: Methods
Class: StudentRegistrationMethods.java

PURPOSE
Refactors code into methods with parameters, return values, void/instance/static methods and overloaded methods.

RUN ON WINDOWS
1. Install a JDK (17 or newer recommended) and ensure java and javac work in Command Prompt.
2. Double-click run.bat, or open Command Prompt in this folder and run run.bat.
3. Edit src\StudentRegistrationMethods.java with Notepad++ and save before running again.
