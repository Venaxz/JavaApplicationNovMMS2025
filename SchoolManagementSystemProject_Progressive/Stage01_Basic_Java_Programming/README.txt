STAGE 01: Basic Java Programming
Class: SchoolManagementSystemProject.java

PURPOSE
Collects the full student registration details and demonstrates variables, types, Scanner, output, String handling and age calculation.

RUN ON WINDOWS
1. Install a JDK (17 or newer recommended) and ensure java and javac work in Command Prompt.
2. Double-click run.bat, or open Command Prompt in this folder and run run.bat.
3. Edit src\SchoolManagementSystemProject.java with Notepad++ and save before running again.

PROGRESSION
This folder is a runnable checkpoint for this assignment stage. The next stage extends the concepts; the complete connected application is in FinalIntegratedProject.
